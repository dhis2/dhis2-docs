# Custom Colors { #custom_theme_color }

For v43+ and with the Global Shell enabled, a user can set a custom theme color for their DHIS2 instance and android application. The color is applied to the header bar visible across all DHIS2 apps.

## Set a theme color

1. Open the System Settings app.
2. Go to the Appearance tab.
3. Under Theme Color, click the color selector.
4. Choose a color from the presets, or type a hex or RGB value directly.
5. Click outside the picker to confirm your selection. The setting saves automatically.

![](resources/images/custom_colors/open_color_palette.png){ width=30% }

![](resources/images/custom_colors/color_selected.png){ width=30% }

5. The header bar will update to reflect the chosen color upon refreshing the page.

**Note**: Text and icon colors in the header bar are automatically adjusted to maintain readability against the selected background.

![](resources/images/custom_colors/new_theme_color.png){ width=30% }

## Remove a theme color

1. Open the System Settings app.
2. Go to Appearance.
3. Next to the current color, click Remove color.

![](resources/images/custom_colors/color_selected.png){ width=30% }

![](resources/images/custom_colors/no_color_selected.png){ width=30% }

4. The setting saves automatically. Refresh the page. The header bar will revert to the DHIS2 default color.

![](resources/images/custom_colors/original_theme_color.png){ width=30% }
